# 위원회 AI 답변 Y/N 피드백

답변 아래의 `Y` 또는 `N` 평가는 파인튜닝에 자동 사용하지 않습니다. 검색·프롬프트 품질을 나중에 분석할 수 있도록 다음 정보를 `committee_chat_feedback` 테이블에 축적합니다.

- 사용자 질문과 최종 답변
- Gemini가 만든 검색 문장과 검색 키워드
- 검색된 청크 ID와 최고 검색 점수
- 사용자에게 표시한 회의록 참고자료
- 조건부 검증 실행 여부와 신뢰도
- Y/N 평가와 평가 시각
- 로그인 사용자인 경우 사용자 ID와 아이디

같은 답변 ID에는 행이 하나만 생성되며, 평가 API는 해당 행의 Y/N 값만 갱신합니다. 전체 PostgreSQL `pg_dump`에 이 테이블과 임베딩 데이터가 함께 포함됩니다.

배포 전에 `prisma/committee_chat_feedback.sql`을 한 번 실행해야 합니다. 마이그레이션 전에도 채팅 답변은 계속 제공되지만 평가 버튼은 표시되지 않습니다.
